## 구현 순서

1. 요구사항과 담당자 답변을 기록한다.
2. 엔티티 설정과 필요한 로직을 구현한다.
3. `scripts/smoke.py`에 요구사항 검증을 추가하고 실행한다.
4. 기존 범용 화면으로 요구사항을 충족하는지 확인하고 필요한 부분만 수정한다.
5. 확인한 결정을 `docs/DECISIONS.md`에 기록한다.

## 검증 방법

- 서버: `uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload`
- 별도 터미널: `python scripts/smoke.py`
- 기존 자동 검증: 루트·정적 파일 서빙, 메타데이터, item 등록·단건/목록 조회·수정·삭제, 기본값·시각 필드, 잘못된 입력과 없는 엔티티·항목 처리.
- 주의: 현재 스모크 테스트는 `item` 정의를 전제로 한다. 해당 정의를 바꾸면 검증 데이터와 기대값도 과제에 맞춘다.
- 화면 수동 검증: `/`에서 엔티티 선택, 등록, 행 클릭 수정, 문자열 필드 검색, 삭제 취소·확인.
